任务流程

  1. 全队状态就绪后共同起飞，到达 0.75 m 世界高度。
  2. 在中心收拢队形，沿配置航路整体前往基地集结区。
  3. 按 0 → 1 → 2 → 3 顺序执行接近、接触、后撤；其余飞机保持集结位置。
  4. 四次接触完成后，全队沿逆序航路返航。
  5. 全队回到各自红框后下降，飞控确认落地后结束任务。

接触确认同时检查冲击事件、接近距离和航向；阶段超时或状态中断会触发任务中止。位置来自伴随定位算法；高度使用 SIM_HEIGHT_ASSIST。独立评估记录 Gazebo 接触事件和真实位置。

图形操作

  1. 打开“四机定位仿真实验台”，选择“四机轮流撞击与返航”。
  2. “中心放大／全场”切换地图视角；中心视图显示 H0–H3 红框与机体尺寸。
  3. 保持“启用四机定位飞行”未勾选，可查看地形、起点和传感器。勾选后点击“启动四机环境”执行任务。
  4. 界面显示当前阶段、当前撞击机、已完成机号，以及每机到红框中心的 ΔX、ΔY、XY 距离。
  5. “估计”是算法计算的返航偏差，“真实”来自 Gazebo 评估。落地记录单独保存最终偏差。
  6. “保存定位报告”导出当前观察区间；“停止本次仿真”结束运行并保留日志。

切换任务或修改地图配置前先停止当前运行。
