# 平面到达时间模型对照

日期：2026-10-16。Gazebo/PX4 四机 SITL；实现提交 `e3553c4`。

## 到达时间的空间定义

旧模型以本机到结构中心的三维距离，除以有界水平速度。目标预测需要的是到达目标平面的时刻，高度差和沿板面的位移不应增加穿面距离。

可选平面模型用任务航向构造单位法向 `n`，计算剩余距离 `d = n · (target - self)` 和初速度 `v = n · velocity`。加速度为正时，沿法向先加速再限速；加速度为零时使用有界匀速模型。目标已在身后、非有限输入、非法速度范围及非单位法向返回无效结果。

模型只改变目标预测的时间，不修改入口、终端参考控制、压力评分、恢复流程或接触时限。默认仍为 `radial`。

| `team_mission.dive_attack` 参数 | 默认值 | 含义 |
|---|---|---|
| `arrival_reference` | `radial` | `radial` 使用原距离模型，`plane` 使用目标平面法向 |
| `arrival_acceleration_enabled` | `false` | 使用加速后限速模型 |
| `arrival_acceleration_mps2` | `1.5` | 模型加速度，m/s²，须大于零 |

平面模式要求 `0 < min_forward_speed_mps <= impact_speed_mps`。配置名或参数无效时启动报错。`dive_aim` 保存使用的模型与加速度开关。

对照配置将 `arrival_reference` 设为 `plane`，启用加速度模型，并设为 3.0 m/s²。该值取自已有原生 `MPC_ACC_HOR=3.0`，没有用本次结果拟合参数；它是预测模型参数，不保证实际执行恒加速度。提交范围仍为 0.9 m，终端参考速度上限仍为 3.0 m/s，最小前推仍为 1.2 m/s。

## 历史记录检查

六组运行的 34 次提交具有可插值穿面记录。使用原记录中的位置、速度和目标中心计算候选时间，评估真值不进入 runner。

| 离线模型 | 诊断平面到达时间平均绝对误差 / ms |
|---|---:|
| 原距离模型 | 166.20 |
| 法向匀速 | 101.47 |
| 法向加速度 3 m/s² | 10.82 |
| 法向加速度 4 m/s² | 9.81 |
| 法向加速度 6 m/s² | 21.90 |
| 法向加速度 8 m/s² | 29.39 |

诊断平面位于结构中心前方 50 mm。排除穿面前已有物理接触的样本后，剩余 29 次中原模型误差 168.37 ms，3 m/s² 候选误差 11.54 ms。改用模型实际预测的中心平面、并排除此前接触后，只剩 10 次，误差分别为 148.62 ms、14.73 ms。有限样本和接触改变轨迹均限制这一离线比较。

最近两组 3 号机的失败还包含横向初速度与剩余可用时间不匹配，以及穿面高度偏高。到达时间修正不能单独解决这些问题。

八次合格压力确认均匹配独立压力记录。前两组共 11 次未确认冲击的等待、恢复参考归零和 ToF 暂停融合检查通过；重复组没有未确认冲击，该恢复检查不适用。

原生 EKF 时间索引输入 11/12 份完整。radial 对照 1 号解锁窗口缺一条 `vehicle_visual_odometry` 引用，完整性检查失败。三组无原生 Navigation failure，导航间隔 P99 为 20.135–20.174 ms，成功 UDP 参考提交最大间隔 25.082 ms，严格 20 ms 上限仍未通过。
