# 元数据预取与导航发布间隔

日期：2026-10-16。单调时钟记录：`0324864`；元数据预取：`3137ec9`。

## 导航与 UDP 提交时刻

`DRONE_PROFILE_RUNTIME=1` 时，已解锁且心跳新鲜的导航周期产生 `navigation_timing` 记录：

| 字段 | 含义 |
|---|---|
| `navigation_wall_us` | 导航发布判定时刻，本机单调时钟，µs |
| `setpoint_submit_wall_us` | 参考报文成功提交给 UDP 套接字后的时刻；未提交为 null |
| `camera_request_attempt_wall_us` | 最近一次元数据读取请求尝试结束的时刻 |
| `sim_time_us` | 当前传感器仿真时间 |
| `offboard_active`、`auto_land_active` | 飞控模式反馈 |
| `unrecoverable`、`setpoint_gap_latched` | 本地失效与控制流保护状态 |

间隔由相邻单调时钟记录相减计算，分辨率为 1 µs；UDP 提交时刻不表示飞控已接收。默认关闭时不产生这些记录。约 0.8 s 的进程暂停用例测得 813.835 ms 导航间隔，预取版测得 813.461 ms；恢复后均锁存控制流中断，停止任务参考并请求原生降落。

## 导航前预取

元数据读取请求从导航周期内移到下一导航槽前 6 ms，仍按 20 ms 绝对槽位调度。迟到时只请求一次并跳过积压槽位；睡眠同时考虑预取和导航截止时刻。

文件访问仍由工作线程执行。导航到期只取缓存结果，读取慢时不等待；帧序号、曝光时间、曝光位姿及 PPM 一致性处理保持原规则。`camera_request` 单独计时请求提交路径。受控暂停用例中，请求到导航开始的中位间隔为 5.987 ms；两组闭环已解锁成员的对应中位数为 5.987–6.026 ms。
