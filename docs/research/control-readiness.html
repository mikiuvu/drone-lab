离线控制就绪状态机参考

日期：2026-10-02 · 工作区：D:\Robomaster code\drone · 范围：纯 Python 设计参考、确定性测试 · 无连接硬件

用途：这是为后续研究和代码实现准备的可执行状态机参考。它只读取显式输入并返回模式、原因、证据和统计指标，不生成 MAVLink 控制消息，不解锁、不起飞、不悬停、不降落，也不替代飞控配置的失效保护。NAVIGATE_REFERENCE_ONLY表示证据满足未来控制器的数据门槛，不表示当前可以安全飞行或保持悬停。

1. 文件与接口

实现位于 research/control_policy.py，测试位于 tests/test_control_policy.py。入口是：

run_control(config=None) -> dict

config可以包含显式时间的samples数组和阈值配置。未提供samples时，run_control({})使用固定的 10 样本故障演示，覆盖有效、过期、重复来源时间、恢复、epoch 重置、缺高度和终止；显式samples=[]才返回空的STANDBY摘要。模块不读取系统时钟。每个样本至少应表达：

输入含义门槛
time_s调用方提供的接收/评估时间，单位秒。只用于判断来源数据年龄，不能替代里程计来源时间。
odom_time_s、可选odom_frame_seq里程计来源样本时间与帧序号。恢复只接受严格递增的odom_time_s；提供帧序列时也要求严格递增。接收时间增长而来源时间重复，不能推进恢复。
estimator_epoch估计器启动/重置代号。缺失时无导航资格；代号变化会丢弃旧恢复进度和旧命令计数。
connection_alive链路或数据源是否仍有连接生命迹象。只描述连接，不等于估计状态有效。
observable_axes可观测坐标轴集合，默认要求x,y,z,yaw。缺少z时不产生导航参考，也不推断可以安全着陆。
position_valid、velocity_valid、yaw_valid估计器对位置、速度、偏航的质量判断。三者都必须为真。
clock_confidence时间对齐置信度。默认至少0.8；当前没有执行同步或漂移估计。
setpoint_time_s、setpoint_epoch目标来源时间与 epoch。setpoint epoch 必须存在并匹配 estimator epoch；其变化独立使旧参考失效。
fresh_odom、fresh_setpoint可选的新鲜度声明。必须是真正的布尔值，且只能与来源时间计算结果一致；True不能绕过缺失或过期来源时间。
terminal_sensor_flags终止级传感器或安全标志，可用数组或布尔字典。任一有效标志会锁存TERMINATED。

2. 模式与转换

STANDBY
尚无导航资格
→
NAVIGATE
参考数据门槛满足
→
DEGRADED
禁止位置控制参考
→
RECOVER
恢复迟滞已满足
→
NAVIGATE
再经确认样本

任意模式出现终止标志都进入TERMINATED并锁存。STANDBY收到无效输入时继续保持STANDBY；已经处于NAVIGATE或RECOVER时，状态失效进入DEGRADED。DEGRADED默认需要 3 个同一 epoch 内严格递增odom_time_s的有效样本；样本必须在 1 秒来源时间窗口内。达到数量后先进入RECOVER，下一份新的有效样本才回到NAVIGATE。重复来源时间、倒退来源时间、epoch 切换都不能满足迟滞。

条件输出模式输出决定请求动作
全部门槛有效，且初次获得资格NAVIGATENAVIGATE_REFERENCE_ONLYNONE
未具备资格或恢复未完成STANDBY / DEGRADED / RECOVERNO_CONTROLREQUEST_CONFIGURED_FC_FAILSAFE
终止级标志，或已锁存终止TERMINATEDTERMINATE_REFERENCE_ONLYREQUEST_CONFIGURED_FC_FAILSAFE

“请求配置的飞控失效保护”是信息输出，不能被解释为代码已经触发了某个具体动作。缺少高度时明确记录missing_altitude_does_not_imply_safe_landing；实现不会输出 land、降落点或伪造高度。

3. 时间、epoch 与旧命令处理

  • 策略只使用样本中的显式时间，因此测试和回放可完全确定。time_s只计算年龄；来源odom_time_s重复或倒退时，样本不会推进恢复计数。
  • 估计器 epoch 或 setpoint epoch 变化会清空来源样本身份、恢复计数和恢复窗口；两者同时变化只增加一次discarded_command_count，同时保留两个独立 reset 指标。
  • 连接断开和状态无效分别输出connection_alive与state_valid。链路还活着时，位置/速度/偏航或时间质量仍可能不合格；链路断开时也不能根据连接字段假设估计器安全。
  • 策略不做坐标变换、轨迹生成、控制律、姿态补偿、限幅或飞控模式切换。通用点导航只在“数据门槛和失效处理”的意义上被引用。

4. 与视觉、ToF 和 UWB 的关系

视觉与 ToF

未来视觉识别、双 VL53L5CX 或融合估计器接入时，必须将结果转换为带采集时间、估计器 epoch、坐标系、单位、质量/协方差、数据年龄和失效标志的测量。视觉置信度不能代替位置有效标志；ToF 有效距离也不能单独证明三维位置可观测。这里的observable_axes是结果合同，不是从原始热力图自动推导的能力。

可选 UWB

UWB 后续必须提供自身测量时间、设备或估计器 epoch、基站几何/解算质量、位置协方差、锚点健康和最大允许年龄。UWB 时间不能直接与飞控 boot time 或 Nano monotonic time 相减；需要明确的时钟映射、同步置信度和漂移上限。UWB 解算有效性需单独检查；单个锚点或退化几何不能自动满足位置门槛。

时钟同步

当前clock_confidence只是输入门槛。生产实现需要记录同步协议、参考源、偏差、漂移、最近同步时间、估计不确定度和跨重启行为；还要规定测量年龄由哪个时钟计算。未完成同步时，策略应保持禁止位置控制参考。

5. 测试覆盖

测试文件包含 31 个确定性用例：

  • 默认故障序列覆盖有效、过期、恢复中的重复来源时间、epoch 重置、缺高度和终止；显式空序列仍为空 STANDBY。
  • 里程计过期、目标过期及连接断开分别产生原因；连接生命和状态有效性分开。
  • 重复odom_time_s即使time_s持续增长也不能满足恢复。
  • 估计器 epoch 与 setpoint epoch 分别校验；同时变化只计一次旧命令上下文失效。
  • 缺少z时保持待机或降级并请求配置的飞控失效保护，不宣称可安全着陆。
  • 有效样本经过 DEGRADED → RECOVER → NAVIGATE 的迟滞路径。
  • 终止传感器标志使 TERMINATED 锁存。
  • 字符串布尔值、NaN 数值和越界配置会被拒绝。
