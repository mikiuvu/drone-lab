# 终端提交的运动条件

日期：2026-10-15。平台：Gazebo/PX4 四机仿真、LicheeRV Nano riscv64。

## 速度与剩余位移

历史重试中存在前向速度较高、垂向仍在上升的提交。例如 `run_20261015_201923` 的 0 号在 23.421 s 提交时，机体系前向速度为 2.451 m/s、垂向速度为 +0.822 m/s，按剩余位移和三轴速度上限计算的前向参考上限仅为 1.380 m/s。该次穿越参考平面时高出结构中心约 519 mm。

`terminalVelocity` 按同一剩余时间缩放水平机体系位移，各分量单位为 m，速度上限单位为 m/s：

```text
T = max(hypot(dx, dy) / horizontal_limit,
        abs(dy) / lateral_limit,
        abs(dz) / vertical_limit)
reference = displacement / T
```

目标须位于机体前方；非有限输入、非正速度上限和退化水平距离返回无效结果。

`terminalEntryVelocityCompatible` 要求前向参考至少覆盖配置的最小前向速度和本机当前前向速度。目标低于本机时，垂向速度不得超过 +0.05 m/s；目标高于本机时，不得低于 −0.05 m/s。该容差允许静止附近的速度估计误差。

新条件与观测新鲜度、入口高度、航向、前向运动和剩余接触时窗共同决定是否提交。默认接近方式在提交范围外继续建立下降运动，进入 0.9 m 提交范围后要求速度相容；条件不满足时使用入口位置控制。`dive_commit_gate` 增加 `terminal_motion_available` 和 `vertical_speed_mps`。

速度比例参与提交准入，实际速度控制继续使用实测水平闭合速度计算垂向参考。后续加速度、姿态和碰撞响应仍需通过闭环验证。

两组分别记录 15、48 条运动条件未满足事件；提交范围外的这类事件不阻止接近准备。重复组停止时，四机距各自起飞点的水平距离为 0.105、0.036、0.016、0.045 m。

第一组的 2 号于 41.461 s 进入失效恢复，42.126 s 时独立物理轨迹已降至世界 Z=−0.048 m，最终在 180.197 s 到达 Z=−96.563 m，属于离开场地承接面后的持续下落。严格恢复检查返回失败，`all_stopped=false`。运行达到时间上限后停止仿真进程，原生着地与停机结果仍保留为失败。两组的恢复阶段均未出现 ARM/OFFBOARD 重试。

两组各有 2/4 架取得合格接触，尚未完成全队任务，也未证明接触成功率提高。未命中后的碰撞恢复、出界和部分成员的独立降落仍需处理。

穿面指标取机体中心到达装甲中心前方 50 mm 的平面；几何接触可能早于穿面。压力事件、接触轮次和穿面误差分别保存。
