两枚 8×8 ToF 能约束哪些位姿方向？

在这个局部、已知地图的实验中，直角高墙可约束 x、y、yaw；单墙丢失沿墙平移，平行走廊丢失纵向平移，开阔区没有距离观测。增加分区数量不能补回缺失的几何方向。默认 2.5 m 高度、水平安装、3 m 物理距离上限时，0.3 m 和 1.1 m 低墙均无返回。

这是安装覆盖和局部退化的实验。它没有验证真实 VL53L5CX 精度、地图关联、SLAM、飞行控制，也没有测量 SG2002 CPU 或 NPU 性能。所有场景都由本模块手工定义。

视场：65° 是对角，不是水平

ST 数据手册列 65° 对角 FoV，并在 Table 2 分别列 45° 水平/垂直 FoV [S1]。默认模型先采用理想方形透视投影，根据对角角度构造相同的水平/垂直轴角：

tan(θdiag / 2) = √2 · tan(θaxis / 2)
θaxis = 2 atan[tan(65° / 2) / √2] = 48.5009°
u, v ∈ {±1/8, ±3/8, ±5/8, ±7/8} · tan(θaxis / 2)
dlocal = normalize([1, u, v])

48.5009° 是上述理想投影的计算结果，不能替代数据手册中的 45°，也不能声称是真实镜头的精确覆盖。设置 fov_model="datasheet_axes" 可用 45° 轴角作对照。数据手册的检测体积依赖环境与配置，其表内值对应规定测试条件；两种理想模型都需要实测分区方向和安装外参。

每个分区是一个有限脚印，并不是一条细激光。ST 员工对光场投影和接收方向的说明见 [S2]。这里仅采样分区中心；默认理想投影在 3 m 光轴深度处，每区横向宽度约 2 × 3 × tan(24.2505°) / 8 = 0.338 m。墙边、窄柱、装甲板可能只覆盖分区的一部分，中心命中与真实输出不是一回事。

三维射线与有限高度墙面

坐标为 x 前、y 左、z 上，正俯仰指向上方。两枚传感器默认沿 x 轴相隔 0.08 m，第二枚偏航 90°。高度已知，机体横滚/俯仰也作为已知量；只估计平面位姿 p=(x,y,ψ)。

Rbody = Rz(ψ) Ry(-body_pitch) Rx(body_roll)
Rsensor = Rz(sensor_yaw) Ry(-mount_pitch) Rx(mount_roll)
o = [x,y,height] + Rbody · sensor_offset
d = Rbody · Rsensor · dlocal
t = n · (wall_anchor - o) / (n · d)
hit = o + t · d

仅保留 t > 0、t ≤ max_range_m、墙段内且 z_min ≤ hit_z ≤ z_max 的命中，并选择最近墙面。墙是竖直有限矩形；没有地面、顶板或低结构的水平顶面。因此本实验说明的是竖直面覆盖，不是完整障碍物检测。

默认输出模式为 axial：measurement = t × dlocal_x；radial 模式直接输出 t。ST 员工说明 L5CX 有片上 radial-to-perpendicular 转换 [S2][S3]。实际固件可能采用逐区修正，本模型只是理想投影，接入硬件前必须确认距离定义。max_range_m 无论在哪种模式都截断物理径向距离，不是 ULD 原始距离门限。

水平安装时，甚至整个理想视场的最低包络也是 2.5 − 3 sin(48.5009°/2) = 1.2678 m，高于 1.1 m。因此在此范围内，默认姿态不可能命中这两种低竖直面。分区中心还比全视场边缘更靠上。采用 45° 轴角也不会改变这个默认漏检结论。改变安装俯仰或飞机倾角后必须重新计算；这个包络公式只适用于水平姿态。

局部可观测性如何计算

每个命中使用已知墙面关联，预测沿原分区方向到该墙面的距离。计算中心差分雅可比时冻结关联；不重新切换墙面，不把有无返回或有限端点切换当成平滑距离观测。这样单墙和走廊的退化不会被离散可见性事件掩盖。

q = (x, y, L ψ),  L = yaw_length_scale_m = 1 m
Jq[:,j] = [h(q+εej) − h(q−εej)] / (2ε),  ε=10⁻⁵ m
Jgeometry = Jq / √N
σ = SVD(Jgeometry)
rank = count(σ > max(10⁻⁷, 10⁻⁶ σmax))

显式长度 L 避免把“每米”和“每弧度”的敏感度直接混在一起。除以 √N 让重复相同分区不凭数量放大几何指标；这些奇异值不是信息协方差、置信度或实际定位精度。改变 L 会改变奇异值和条件数，几何秩通常不变。秩 3 只表示这一位置、姿态和关联附近可局部辨识，不能保证全球唯一、关联正确或连续航迹可用。

参数为 height_m=2.5, max_range_m=3, mount_pitch_deg=0, yaw_separation_deg=90, noise_mm=30。当前位姿为 (0,0,0)，高墙高 4 m，位于 x=2 或 y=2；走廊墙位于 y=±1。所有墙段有限且足够长，端点可见性未用于估计。

俯仰对照：这里正俯仰向上，+30° 仍使两种低墙无返回；界面不应把它标为下俯。保持默认高度和距离，−30° 下俯使 1.1 m 低墙命中 28 个分区中心、秩 3，但 0.3 m 低墙仍为 0。一个刻意覆盖两种低墙的组合是 height_m=2.5, mount_pitch_deg=−40, max_range_m=4：0.3 m / 1.1 m 低墙分别命中 16 / 48 个中心，两者局部秩均为 3。4 m 在这里仅是几何假设，未保证真实材质和环境下的有效测距。见 下俯对照快照。

直角墙的默认 24 次蒙特卡洛中，平移 RMSE 为 0.03211 m，yaw RMSE 为 0.16376°。噪声标准差假定为 30 mm，同传感器分区相关系数为 0.6，种子为 2027（各场景用加序号的种子）。默认相关性比完全独立分区的假设更保守，但 0.6 没有实测保证；可用 1.0 对照完全共同噪声。共同偏差、混合像素和错误关联仍可能更差。这些数值只说明给定噪声假设如何传播；它们是理想中心射线、准确外参、已知地图和关联、较好初值下的乐观结果。其他不可观测场景不输出完整位姿 RMSE。

固定偏差不会随分区数量消失：测试中共享 +50 mm 距离偏差在直角墙场景造成 x、y 各约 −50 mm 偏差。若飞机以 1 m/s 沿 x 移动，100 ms 旧帧且不补偿时间，零噪声估计位置偏差为 −0.1 m。时延参数是合成采集年龄，不是电脑执行时间。

Windows 电脑上默认运行约 0.11 s，集成耗时要求为小于 2 s。实际运行时间依机器、环境和额外蒙特卡洛次数变化。可复核数据保存在 结果快照 与 验证记录。

从模拟到硬件还缺什么

  1. 逐区光学方向、输出距离定义、安装外参、机体姿态和高度的误差标定。已知高度/姿态的假设可能掩盖真实耦合。
  2. 分区有效状态、信号强度、反射率、环境光、窗口、互扰、多目标与混合像素。中心射线可能漏掉真实可见物体，也可能把部分覆盖误当稳定平面。
  3. 噪声的空间/时间相关性及系统偏差。当前只加入帧内同传感器等相关高斯噪声；跨传感器相关、时间相关与重尾离群点未建模。
  4. 未知数据关联、地图误差、场地对称性、移动障碍和反复遮挡。当前蒙特卡洛提前知道正确墙面，无法评估关联失败。
  5. 不同采集时间的时间戳、姿态插值和融合。演示时延只影响 x/y/yaw，未模拟 roll/pitch/高度随时间变化。
  6. 连续运动中弱方向的补充观测，以及视觉、IMU、可选 UWB 的质量与失效处理。本模块没有融合这些传感器，不能直接给出最终飞行估计器架构的验证结论。
