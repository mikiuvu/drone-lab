# 滑轨预测与入口对准验证

日期：2026-10-15。场景：Gazebo/PX4，`rmuc_2026_sentry26`，四机 `team_contact`。

## 预测参数

`team_mission.dive_attack` 提供以下参数：

| 参数 | 默认值 | 单位及作用 |
|---|---:|---|
| `linear_speed_limit_mps` | 1.0 | m/s，线性预测的横向速度上限 |
| `linear_reflection_half_width_m` | 0.0 | m，已知滑轨半行程；0 关闭边界反射预测 |
| `robust_linear_enabled` | false | 使用独立曝光的短窗运动拟合 |
| `entry_alignment_enabled` | false | 在入口跟随预测横向位置，满足连续对准条件后提交 |
| `entry_alignment_horizon_s` | 0.75 | s，入口对准的预测时间 |
| `entry_alignment_tolerance_m` | 0.06 | m，入口横向容差 |
| `entry_alignment_speed_tolerance_mps` | 0.2 | m/s，入口静止与横向跟随速度容差 |

短窗拟合保留最近 0.8 s、最多 24 个独立曝光，至少需要 4 点与 200 ms 时间跨度。速度由间隔至少 160 ms 的样本对斜率中位数计算；位置由传播到最新曝光的样本中位数计算。模型超过 150 ms 未更新即失效，重复和倒序曝光不进入拟合。

入口对准要求位置、高度、航向、速度和预测有效性持续满足 100 ms。定位失效时，入口对准阶段的姿态保持使用入口高度。

预测输入来自视觉观测，X/Z 使用静态结构中心。边界反射依赖配置中的已知半行程；评估器的瞬时滑轨真值只用于离线比较。

测试地图均位于 `build/nano-entry-alignment`。四组配置使用横向速度上限 0.3 m/s、反射半行程 0.28 m；后三组还将周期预测上限设为 0.85 s。

| 配置 | 运行目录 | 任务内确认接触成员 | 停止时仍解锁成员 |
|---|---|---|---|
| 有界预测 | `run_20261015_060630` | 2、3 | 无 |
| 有界预测与入口对准 | `run_20261015_061003` | 无 | 无 |
| 短窗拟合与入口对准 | `run_20261015_063041` | 2 | 3 |
| 短窗拟合，入口对准关闭 | `run_20261015_063550` | 0、3 | 1、2 |

每种配置各运行一次，视觉与启动时序不同，不能据此估计成功率。入口对准没有取得稳定闭环收益，生产地图保留原配置。

`run_20261015_063550` 的 2 号在 52.228 s 产生达标压力事件，但其 CONTACT 轮次已于 51.541 s 结束，因此任务内接触确认仍为失败。压力事件数、任务接触确认与停机状态分别保留。

该运行的重试包括：1 号在 32.001 s 使用中位落点，提交时 Vx 为 −1.641 m/s；2 号在 50.761 s 提交时 X 为 12.458 m、Vx 为 −3.551 m/s，已经越过结构中心 X=11.584 m。首轮目标预测较好仍可能伴随较大机体横向偏差，例如 2 号在 40.201 s 提交后，预测时刻 Y 误差约 6.1 mm，穿面机体 Y 偏差约 −192.5 mm。

穿面指标采用机体中心到达装甲中心前方 50 mm 的平面，按时间插值。实际压力事件还受机体姿态、几何和轮次时窗影响。

## Nano 算法耗时

Nano 上的 riscv64 musl 静态 `test_intercept` 返回 0。20,000 次合成短窗拟合与预测：平均 11.2464 μs，P99 12.48 μs，最大 167.12 μs。

数据文件：`build/nano-entry-alignment/board-tests/result.json`。这些耗时覆盖独立算法调用，不包含图像处理、导航发布和通信。

## 降落终态

路线屏障可以跳过失效成员，终态检查覆盖所有成员的新鲜状态、着地和停机反馈。LAND_ALL 阶段收到着地反馈后即可请求停机；仍解锁、未着地或状态超时的成员阻止进入 COMPLETE/ABORTED。失效成员的停机确认不依赖水平定位恢复。

测试覆盖正常全队降落、部分失效、全队失效、陈旧状态和可变机群数量。完整 CTest 14/14、无 OpenCV CTest 13/13 通过。

闭环 `run_20261015_064458` 使用有界预测地图，0、1、3 号取得任务内有效接触，2 号超时后返航。四架的飞控着地和停机确认均已收到，最后一架于 66.278 s 确认停机，任务于 67.101 s 进入 ABORTED。`landing-confirmation/recovery.json` 的 `all_stopped` 为 true。

闭环报告及源码、配置、二进制哈希保存于 `build/nano-entry-alignment/{bounded,aligned,robust,robust-only,landing-confirmation}`。`robust-only/recovery.json` 的停止确认失败：1、2 号仍解锁，未获得飞控着地确认。
