全场地形与四机定位实验

四机基地撞击、中央起飞点与返航操作

当前重点：无 UWB 基站条件下，四架飞机如何利用稀疏测距、机间测距和已知地图保持同一坐标系。

怎样打开

  1. 双击项目根目录的 四机定位仿真实验台 快捷方式，即可直接进入第 ⑦ 页；原有 Drone Lab 快捷方式仍可使用。
  2. 打开第 ⑦ 页 Gazebo 四机，地图选 Sentry26 2026 全场地形。
  3. 先使用启动四机环境查看真实传感器和定位有效率。Gazebo 窗口可旋转、缩放查看地形。
  4. 任务 hover 为悬停实验，survey 为实验航线。勾选启用四机定位飞行后再启动，才会发送虚拟解锁和飞行指令。默认未勾选。
  5. 观察每机误差、有效率、机间距离误差和全队共同平移漂移；使用保存报告导出当前观察区间。
  6. 结束时点击停止，本次日志保留在 simulation/runtime/run_日期时间。

一轮仿真运行期间先停止，再切换地图、安装角或任务。

怎样理解定位结果

  • 绝对 XY 误差：与初始化时建立的地图坐标系比较。
  • 机间距离误差：编队相对形状是否保持。
  • 共同平移漂移：四架是否一起漂离地图，距离误差很小也可能出现这种失败。
  • 结构有效 / peer 有效：当前依赖地形还是机间约束；peer 自己也必须有独立结构来源，避免互相循环确认。
  • 路径长度与位移：静止或很短的实验不能证明全场移动定位。

3 颗 8×8 ToF 看见水平地面时，水平位置可能不可观测。准确高度也无法补足水平信息；无基站 UWB 本身只给相对约束。这正是需要在此环境中研究的退化工况。

验证实际结果
地形和深度坐标12 路静态深度与网格射线逐格命中一致，最大距离差 0.94 mm。仅验证当前理想渲染几何。
30 秒仿真悬停实验run_20261002_200421：四机均实际解锁起飞，最终高度 1.797–1.801 m。四机完整日志 XY RMSE 分别 0.069 / 0.108 / 0.147 / 0.009 m；最大误差最高 0.749 m。包含初始化过程，没有剔除无效估计，没有做轨迹坐标拟合。
较长航线失败run_20261002_195848：两机发生失锁和发散，另外两机完整日志 RMSE 约 0.044 / 0.034 m。该次 trial 判为失败。
构建与自动检查126 项 Python 测试 + 29 项子测试通过；C++ companion 与 UWB 遮挡测试各 1/1 通过；RISC-V 重新编译通过，未在 Nano 实机运行。
静态网格资源C++ 常驻容器容量约 4.89 MiB；电脑基准约 15 μs/射线。该基准在电脑运行，容量不含构建临时内存。

当前适合研究地形可观测性、机间约束、失锁原因和恢复策略。survey 仍是实验功能。真实板卡、双天线型号、射频误差、相机 ISP 与执行耗时待硬件接入后校准。
