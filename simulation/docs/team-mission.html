定位输入

成品光流模块提供机体系水平速度，IMU 提供姿态和运动预测，ToF 对匹配可靠的场地结构进行漂移修正。UWB 机间距离与方位把可信参考传递给其他飞机；参考携带来源、序号和传播路径，重复参考和环路被剔除。

无基站时使用已知起飞位置初始化共同坐标系。有基站时，根据固定坐标和测距融合；至少两条质量合格、方向独立的近期测距才能提供完整 XY 参考。高度由仿真环境直接提供。

光流有效率、定位置信度、ToF／UWB 融合计数和每机误差均可在实验台查看。接口字段见传感器接口与机群配置。

任务流程

  1. 全队状态就绪后共同起飞，到达 0.75 m 世界高度。
  2. 在中心收拢队形，沿配置航路整体前往基地集结区。
  3. 按配置的机号顺序执行接近、接触、后撤；下一架提前到基地上侧待命点，已接触飞机从下侧退出并集结。
  4. 接触轮次完成后，全队沿逆序航路返航。
  5. 全队回到各自红框后下降，飞控确认落地后结束任务。

接触确认同时检查冲击事件、接近距离和航向。单机数据中断时该机等待恢复，其余飞机继续执行；长期失联的飞机退出后续轮次，恢复及时则重新加入。默认不设阶段期限；可用 stage_timeout_s 设置主动返航期限。界面状态和日志写入失败会重试，错误计数写入运行状态。

飞行数据可视化

点击实验台的“飞行数据曲线”，打开当前运行记录。窗口包含 XY 轨迹、高度、速度、水平定位误差、航向、置信度和任务阶段条。

  1. 选择“全部无人机”对比机群，或选择单机展开 VX、VY、VZ、光流有效性和 XY 有效性。
  2. 拖动底部时间轴或点击曲线，查看同一时刻的机体位置、数值和任务阶段；“播放”按 0.25×–4× 速度回放。
  3. 勾选“跟随最新数据”查看运行中的曲线；取消勾选可停留在指定时间并使用工具栏缩放、平移。
  4. “选择运行目录”打开历史日志；“导出图片”保存 PNG/PDF，“导出 CSV”保存当前所选机号的采样曲线。

曲线时间轴使用仿真时间，包含启动准备阶段。估计曲线按不小于 0.05 s 的间隔取样；水平误差使用时间戳对齐的真实位置，前后样本均在 0.10 s 内时线性插值。没有可匹配真实位置时留空。红色空框为起飞位置，虚线为真实轨迹。

图形操作

  1. 打开定位仿真实验台，选择“多机轮流撞击与返航”，设置“启动数量”。
  2. 需要固定基站时勾选“启用固定 UWB 锚点”；坐标在地图 JSON 的 uwb_anchors 中配置。
  3. “中心放大／全场”切换地图视角；中心视图显示各机红框与机体尺寸。
  4. 保持“启用多机定位飞行”未勾选，可查看地形、起点和传感器。勾选后点击“启动多机环境”执行任务。
  5. 界面显示飞行计时、当前阶段、当前撞击机、已完成机号，以及每机到红框中心的 ΔX、ΔY、XY 距离。
  6. “估计”是算法计算的返航偏差，“真实”来自 Gazebo 评估。落地记录单独保存最终偏差。
  7. “保存定位报告”导出当前观察区间；“停止本次仿真”结束运行并保留日志。

切换任务或修改地图配置前先停止当前运行。
