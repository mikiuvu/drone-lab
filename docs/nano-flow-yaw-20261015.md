# 光流融合中的航向不确定度

日期：2026-10-15。平台：Gazebo/PX4 四机仿真、LicheeRV Nano riscv64。

## 测量模型

光流观测机体系 FLU 的前向和左向速度，预测值为 `(Rᵀ v_ENU).head<2>()`。滤波状态包含世界航向 yaw，原融合只对世界速度求导，将航向作为已知量处理，遗漏了航向与速度之间的测量耦合。

雅可比增加 yaw 列 `(Rᵀ [vy, -vx, 0]).head<2>()`，保留原有完整 roll/pitch/yaw 旋转和速度列。观测质量、方差、时效门限与控制参数保持一致。

回归在四个不同航向及非零滚转、俯仰、垂向速度下，以数值差分计算独立雅可比，核对状态修正和 Joseph 协方差更新；同时检查世界航向与速度共同旋转不改变机体系观测，以及更新后协方差对称、半正定。旧融合首先在航向修正断言处失败，补齐后通过。

使用默认地图三次完整运行，返航窗口取 RETURN_ALL 至 LAND_ALL。每条估计匹配不晚于该时刻的独立物理位姿，最大时间差为 40 ms。XY 指水平位置误差；航向误差按最短包角计算。

## 接触与停机

| 运行 | 合格物理接触 | 未完成成员 | 终态 |
|---|---|---|---|
| `run_20261015_191200` | 无确认 | 四架均未完成轮次 | 77.681 s，ABORTED |
| `run_20261015_192423` | 0、1、2 号 | 3 号弱接触后独立降落 | 56.961 s，ABORTED |
| `run_20261015_192708` | 0、2、3 号 | 1 号接触阶段失效后独立降落 | 99.641 s，ABORTED |

新融合两次共六次合格接触均来自物理压力记录，峰值为 101.983–234.487 N。六个接触后返航机次最终距各自起飞点为 0.010–0.067 m。两次四机均取得 PX4 原生着地、未解锁和伴随停止时未解锁确认，严格恢复检查通过。

第一组的 3 号压力记录为 47.539 N，判为不合格接触；最终距起飞点为 5.354 m。第二组的 1 号没有取得合格接触，最终距起飞点为 12.373 m。该机定位失效后，返航窗口的估计 XY 误差 RMSE 达到 115.959 m，不能用于任务位置控制。

第二组 1 号从 37.661 s 判为失效，到原生着地确认 98.933 s，间隔 61.272 s。着地条件累计受水平运动阻塞 60.520 s、低推力条件阻塞 39.648 s、垂向运动阻塞 20.624 s，多个条件可同时阻塞。分析窗口内 2043 条外部速度记录有 1958 条被禁用。接触失败与定位失效后的独立降落仍需继续处理。

以 30 Hz 提交视觉帧、PnP 失败后绿灯回退的配置运行 60 秒，复用原测试图像、地形和 2093 条历史视觉位置，四个输入文件哈希一致。

| 实际完成视觉 / Hz | 29.05 | 28.88 |
| CPU / % | 95.26 | 95.48 |

| 导航间隔最大值 / ms | 24.089 | 25.049 |
| 主循环计算超过 10 ms / 次 | 224 | 166 |

两组平均频率接近，但严格的逐次 20 ms 导航间隔和 30 Hz 视觉吞吐仍未达到。历史程序与当前程序还包含其他阶段的修复，表中差异不能全部归因于单条雅可比改动。

当前负载完成 6000 次 IMU 预测和 3000 次导航，未跳过主循环槽位；光流与高度融合均值为 0.116 ms、P99 为 0.195 ms。板端只执行记录输入的算法回放，传感器采集和飞控执行不在该计时内。

原始结果和输入、源码、二进制清单位于 `logs/nano-flow-yaw/current-30hz/`，对照汇总为 `build/nano-flow-yaw/load-comparison.json`。负载停止后核对了板端进程、启动 ID 和结果哈希，并删除该次临时目录。
